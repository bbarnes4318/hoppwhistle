⚠️ CRITICAL: ALWAYS USE --no-cache FOR BUILDS ⚠️
Docker layer caching will cause builds to skip code changes!

Rebuild API (no cache):

Rebuild Web (no cache):
docker compose -f docker-compose.yml build web --no-cache && docker compose -f docker-compose.yml up -d web --no-deps
